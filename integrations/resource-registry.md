# Resource Registry

External resources are optional and may change. Re-check the official project source before relying on specific commands, APIs, package versions, or licensing.

| Resource | Optional role | Local fallback in this repository | Integration rule |
|---|---|---|---|
| SkipperUI | UI pattern inspiration | `references/design-foundations.md`, `references/visual-hierarchy.md` | Use only accessible patterns and permitted components/assets. |
| Venegency UI | Visual direction inspiration | `references/design-foundations.md`, `references/landing-page-patterns.md` | Treat as inspiration, not a dependency. |
| Animaster LAB | Motion inspiration | `references/motion-engineering.md` | Recreate behavior with project-compatible code; check asset terms. |
| Impeccable | UI diagnosis mindset | `SKILL.md`, `references/quality-checklist.md` | Follow local audit workflow if unavailable. |
| transitions.dev | Transition patterns | `references/motion-engineering.md` | Verify current framework support and APIs. |
| GSAP | Complex animation engine | `references/motion-engineering.md` | Confirm dependency/version and plugin license before use. |
| Claude Git skill | Git hygiene concepts | Git section in `SKILL.md` | Use the current repository's instructions and safe Git operations. |
| `/make-interface-feel-better` | Interaction polish checklist | `references/quality-checklist.md` | Do not claim the command ran unless available and invoked. |

This registry intentionally avoids hard-coding unverified URLs or version numbers. Update it when resources are checked against their authoritative source.
