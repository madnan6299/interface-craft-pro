# Optional Integrations

Interface Craft Pro is designed to remain useful when external resources are unavailable, renamed, rate-limited, or changed.

## Operating rule
The repository's own reference documents are the default fallback. External tools and libraries are optional accelerators, not runtime requirements. Never state that an external skill, package, website, or plugin was used unless it was actually accessible and used in the current task.

## Safe integration workflow
1. Check the project's installed dependencies and current versions.
2. Check the official source for current APIs and license/usage terms when online access is available.
3. Prefer documented, version-compatible APIs.
4. If unavailable, use the local guidance and established project conventions.
5. Record uncertainty and do not fabricate API names, installation status, or test results.

## Intellectual property
This repository contains original guidance, not a mirror of third-party source code, paid components, or proprietary assets. Do not bulk-copy external libraries. Reimplement general design ideas independently and follow the original license and attribution requirements for any code or assets that are actually reused.
