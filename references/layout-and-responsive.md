# Layout and Responsive Design

- Start from content and task constraints, not device mockups.
- Use fluid containers, CSS Grid/Flexbox, min/max constraints, and wrapping.
- Prefer content-driven breakpoints; test where content stops fitting.
- Avoid fixed dimensions for variable content.
- Give dense components a narrow-screen strategy: wrap, stack, intentional scroll, collapse, or simplify.
- Test phone, tablet, laptop, and wide desktop widths.
- Check navigation, dialogs, sticky elements, sidebars, charts, forms, tables, and long content.
- Ensure zoom and larger text do not hide actions.
- Keep touch targets comfortable.
- Distinguish intentional table scrolling from accidental page overflow.
