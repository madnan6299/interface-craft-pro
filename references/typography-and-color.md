# Typography and Color

## Typography
Use a small consistent type scale with clear heading/body/label roles. Choose readable line height and paragraph measure. Use tabular numerals for aligned quantities where supported. Test long names, currency, dates, localization, and mixed scripts.

## Color
- Define semantic roles instead of scattering literal colors.
- Check text, icons, borders, focus rings, and controls in each theme.
- Maintain meaningful contrast and never use color as the sole status cue.
- Pair status colors with text, icon, or shape.
- Check light and dark themes with real content and states.
- Avoid hard-coded colors that break theme switching.
