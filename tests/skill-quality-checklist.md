# Skill Quality Checklist

- [ ] Instructions are clear enough to follow without external resources.
- [ ] External resources are optional, not mandatory dependencies.
- [ ] Fallback paths are documented.
- [ ] No third-party code/assets are mirrored without permission.
- [ ] Workflow begins with repository discovery and audit.
- [ ] UX priorities distinguish blockers from polish.
- [ ] Responsive behavior and accessibility are first-class requirements.
- [ ] Animation guidance covers purpose, reduced motion, performance, and cleanup.
- [ ] Existing business logic, API contracts, and permissions are preserved.
- [ ] Build/test claims require actual execution.
- [ ] Final report lists changed files, verification, and limitations.
- [ ] Evaluation cases cover different UI types and missing dependencies.
