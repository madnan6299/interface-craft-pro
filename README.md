# Interface Craft Pro

A reusable AI-agent skill for production-minded UI/UX refinement, responsive design, accessibility, purposeful motion, GSAP workflows, and disciplined Git review.

## Files
- `SKILL.md` — full interface improvement workflow.
- `references/quality-checklist.md` — implementation and review checklist.
- `examples/agent-task-template.md` — reusable task prompt.

## Use
Read `SKILL.md` before starting a UI/UX task. Audit first, prioritize usability and accessibility, implement real interaction states, verify the result, and report checks honestly.

## References
SkipperUI, Venegency UI, Animaster LAB, Impeccable, transitions.dev, GSAP skill, Claude Git skill, and `/make-interface-feel-better` are reference points when available. This repository does not bundle third-party source or assets; review each project's license before reuse.
