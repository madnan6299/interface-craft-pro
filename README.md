# Interface Craft Pro v2.0

A self-contained UI engineering skill for AI coding agents and developers. It combines UX diagnosis, visual systems, responsive design, accessibility, interaction states, purposeful motion, performance, and evidence-based verification.

**Core promise:** the skill remains useful even if external UI libraries, websites, plugins, or slash commands are unavailable.

## Quick start
1. Read SKILL.md.
2. Inspect the target project and preserve its conventions.
3. Open only relevant guides under references/.
4. Use integrations/ for optional resources and fallbacks.
5. Start from a template under templates/ when useful.
6. Verify using tests/ and references/quality-checklist.md.

## Included
- Design foundations, hierarchy, typography, color, and responsive layouts.
- Accessibility, interaction patterns, forms, and dashboard/landing-page guidance.
- Motion principles, GSAP-oriented recipes, and performance guidance.
- Optional resource registry and offline fallbacks.
- Audit, implementation-plan, and final-review templates.
- Examples and evaluation cases for common interface work.

## Repository map
- SKILL.md: agent entry point and end-to-end workflow.
- references/: original, portable implementation guidance.
- integrations/: optional tools/resources and fallbacks.
- templates/: reusable workflow documents.
- examples/: task briefs for common interface types.
- tests/: skill quality checks and evaluation scenarios.

## External resources and reuse
External resources are references, not runtime dependencies. Their availability, terms, APIs, and licenses can change. This repository contains original guidance rather than copied third-party source, proprietary assets, or full designs. Check upstream terms before reusing external material.
